# Lab Timer & Practice Tracker

## Problem

This application helps students track solved practice
problems and the time spent working.

## Approach

Explain how the app uses useState, useEffect,
conditional rendering, lifting state up, and a custom hook.

## How to Run

1. Install Node.js and Expo Go.
2. Open the project folder in VS Code.
3. Run npm install if dependencies are not installed.
4. Run npx expo start.
5. Open the app in Expo Go.
